## What I build

| Focus | What that looks like |
| --- | --- |
| **AI & agents** | LLM-backed product features, agent gateways with RBAC and cost attribution, and AI-driven test automation |
| **Backend platforms** | Contract-first FastAPI services (OpenAPI 3.1) that generate typed TypeScript and Swift client SDKs |
| **Frontend** | React / Next.js apps and installable PWAs on a Tailwind v4 + `motion` stack |
| **Native mobile** | SwiftUI iOS clients with widgets, tests, and CI, consuming the same generated API contract |
| **Platform & infra** | Azure Container Apps, Cosmos, Durable Functions, Supabase, AWS Amplify, Bicep, and GitHub Actions |
